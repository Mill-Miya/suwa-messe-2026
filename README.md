# 諏訪圏工業メッセ2026｜見学記録

2026年11月13日14:30〜16:00の展示会見学向けに作成した、スマートフォン・PC対応の静的Webアプリです。主催者の公式アプリではありません。

## 利用先
https://mill-miya.github.io/suwa-messe-2026/

## できること
- 2026年の出展企業・団体337件を検索、東西体育館別に絞り込み
- 重点20件の企業研究、**「残りの重点」** で未訪問・見送り以外だけを確認
- エリア順の簡易ソート（東体育館の番号帯→西体育館）。**実際の最短経路ではない**ため公式フロアマップを参照
- **「東142」** などの館名＋ブース番号検索
- **独自のブース番号案内盤**：東体育館1F・西体育館1F/2Fの番号索引、共同出展を含むブース詳細、各企業からの強調表示。物理的な通路・位置関係の図ではなく、公式フロアマップの画像やデザインを複製しない方式
- **方角確認**：対応スマートフォンで「方角センサーを使う」を押した場合のみ許可を要求。北を基準にした端末上辺の方角を表示。位置情報は取得せず、建物内の磁気干渉とブラウザ対応に注意
- 訪問済みと再訪希望を**独立して**記録（同時設定可能）
- 見送り、自由メモ、件数集計
- JSONバックアップ／復元（旧バージョン1および現行バージョン2）とCSV出力
- 「最新版を読み込む」でホーム画面ショートカットから更新確認
- Service Workerキャッシュによるオフラインでの企業一覧表示（事前にオンラインで読み込みが必要）

## 記録の互換性と注意点
- ローカルストレージの既存キー `suwa_messe_2026_v1` を維持し、旧版の訪問記録とメモを読み込みます。
- 旧形式の「訪問済」を訪問済みフラグへ、「再訪希望」を再訪フラグへ移します。旧形式から両方が同時に設定されていたかは復元できません。
- 記録はそのブラウザ・ホーム画面アプリ内に保存され、GitHubへの送信・自動同期はされません。
- iPhoneのSafariとホーム画面版では保存領域が異なる場合があります。**当日は同じショートカットから使い、事前にJSONバックアップを保存してください。**
- 最初の公開版から更新した直後は、旧Service Workerの影響で前バージョンが一度だけ表示されることがあります。ショートカットを閉じて再度起動、必要なら「最新版を読み込む」を使ってください。
- 企業の事業内容は一部「要確認」です。ブース位置と展示内容は当日の会場案内を優先してください。
- 公式PDFは外部サイトのため、オフラインでは開けない場合があります。
- ブース番号案内は実際の歩行ナビではありません。コンパスの方角とブース番号を組み合わせて正確な行先を判断する用途には使用できません。
